#b4n1-нотариус

Докажите, что вы выполнили и когда.

b4n1-notary запечатывает проект в один корень Меркла и записывает портативный файл доказательства. Проверьте его позже или передайте клиенту, и ответ будет в одной строке: проверено или первый файл, который больше не соответствует.

## Почему это важно

Контроль версий записывает, что изменилось. Он не фиксирует, что именно вы доставили в тот или иной день: тег может перемещаться, а архив можно переархивировать. Корень Меркла для каждого файла с отметкой времени является доказательством, которое не зависит от доверия к человеку, создавшему его.

## Установить

— Python: pip install b4n1-notary
- JavaScript: npm install b4n1-notary
- Java: com.b4n1:b4n1-notary:0.2.0
- .NET: dotnet добавить пакет B4n1.Notary.
- Ruby: установка драгоценного камня b4n1-нотариус
- PHP: для композитора требуется нотариус b4n1/b4n1
- Перейти: перейдите на github.com/B4N1-com/b4n1-notary/sdks/go

Каждый пакет содержит предварительно скомпилированные двоичные файлы для Linux, macOS и Windows. Никакой компилятор не требуется и больше нечего устанавливать.

## Что ты можешь сделать

- Запечатайте дерево: штамп печатает количество файлов, корень Меркла и путь доказательства.
- Проверить позже: проверка повторно вычисляет корень и называет все несоответствия.
- Привязка к биткойну:verify-ots проверяет квитанцию ​​OpenTimestamps с введенными кодами выхода.
- История аудита: в истории перечислены все уже запечатанные доказательства.
