# b4n1-公証人

何をいつ納品したかを証明します。

b4n1-notary は、プロジェクトを 1 つのマークル ルートに封印し、移植可能な証明ファイルを書き込みます。後で検証するか、クライアントに渡すと、答えは検証済み、または一致しなくなった最初のファイルという 1 行になります。

## なぜそれが重要なのか

バージョン管理は変更内容を記録します。特定の日に何を配信したかは正確には記録されません。タグが移動したり、アーカイブが再圧縮されたりする可能性があります。すべてのファイルに対するタイムスタンプ付きのマークル ルートは、ファイルを作成した人の信頼に依存しない証拠です。

## インストール

- Python: pip install b4n1-notary
- JavaScript: npm install b4n1-notary
- Java: com.b4n1:b4n1-notary:0.2.0
- .NET: dotnet パッケージ B4n1.Notary を追加
- Ruby: gem install b4n1-notary
- PHP: コンポーザーには b4n1/b4n1-notary が必要です
- 移動: github.com/B4N1-com/b4n1-notary/sdks/go を取得します。

すべてのパッケージには、Linux、macOS、および Windows 用のプリコンパイルされたバイナリが含まれています。コンパイラは必要なく、他にインストールするものは何もありません。

## あなたにできること

- ツリーをシールする: スタンプはファイル数、マークル ルート、証明パスを印刷します。
- 後で検証する: 検証では、ルートが再計算され、不一致があれば名前が付けられます。
- ビットコインのアンカー: verify-ots は、入力された終了コードを使用して OpenTimestamps のレシートをチェックします。
- 監査履歴: 履歴には、すでに封印されたすべての証拠がリストされます。
