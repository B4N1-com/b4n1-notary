# b4n1-공증인

무엇을, 언제 전달했는지 입증하세요.

b4n1-notary는 프로젝트를 하나의 Merkle 루트로 봉인하고 이식 가능한 증명 파일을 작성합니다. 나중에 확인하거나 클라이언트에게 전달하면 대답은 한 줄입니다. 확인되었거나 더 이상 일치하지 않는 첫 번째 파일입니다.

## 그것이 중요한 이유

버전 관리는 변경된 내용을 기록합니다. 특정 날짜에 정확히 무엇을 전달했는지 기록하지 않습니다. 태그를 이동할 수 있고 아카이브를 다시 압축할 수 있습니다. 타임스탬프가 포함된 모든 파일에 대한 머클 루트는 해당 파일을 생성한 사람의 신뢰 여부에 달려 있지 않다는 증거입니다.

## 설치

- Python: pip install b4n1-notary
- 자바스크립트: npm install b4n1-notary
- 자바: com.b4n1:b4n1-notary:0.2.0
- .NET: dotnet 추가 패키지 B4n1.Notary
- 루비: gem 설치 b4n1-notary
- PHP: 작성기에는 b4n1/b4n1-공증인이 필요합니다.
- 이동: github.com/B4N1-com/b4n1-notary/sdks/go로 이동하세요.

모든 패키지에는 Linux, macOS 및 Windows용으로 사전 컴파일된 바이너리가 포함되어 있습니다. 컴파일러가 필요하지 않으며 설치할 것도 없습니다.

## 당신이 할 수 있는 일

- 트리 봉인: 스탬프는 파일 수, 머클 루트 및 증명 경로를 인쇄합니다.
- 나중에 확인: 확인은 루트를 다시 계산하고 불일치 이름을 지정합니다.
- 비트코인의 앵커: verify-ots는 입력된 종료 코드로 OpenTimestamps 영수증을 확인합니다.
- 감사 내역: 내역에는 이미 봉인된 모든 증거가 나열됩니다.
